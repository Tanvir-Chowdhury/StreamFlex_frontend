Usage Guidelines

Accessibility

  • Maintain WCAG AA contrast ratios (4.5:1 for normal text)
  • Use white text on dark backgrounds
  • Test color combinations for readability
  • Provide alternative indicators beyond color alone

Brand Consistency

  • Use brand purple (#8B5CF6) for primary actions
  • Apply gradients sparingly for maximum impact
  • Maintain dark theme throughout the platform
  • Use accent colors purposefully for status indicators

Implementation

  • Use CSS custom properties for consistency
  • Implement Tailwind classes where available
  • Test colors across different devices and screens
  • Document any custom color variations
